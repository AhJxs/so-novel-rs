# Changelog

## [0.7.3] - 2026-11-25

### Added

- **滚动模式全书连续**：章节首尾相接，滚轮一路往下读，右侧滚动条反映整本书而不是当前章；
  内容按视口虚拟化渲染，进过视口的章用实测高度，其余按字数估算，几千章的书也不掉帧。
- **滚轮阻尼**：滚动不再是「跳一格」而是约 180 ms 的平滑推进，连续滚轮会顺滑叠加；
  键盘翻页与方向键同样平滑，目录·书签跳转、Home / End 与模式切换仍是瞬移。

### Changed

- **侧边栏品牌行**：logo 与标题左对齐到菜单图标那一列，标题恢复正常大小写（不再全大写）、
  字重加一档，过长时省略而不是顶破侧栏。
- **构建**：CI 工具链统一用最新 stable，rustfmt 不再依赖 nightly；清掉 Rust 1.100 新增的 clippy 告警。
