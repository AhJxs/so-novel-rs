# Changelog

## [0.7.1] - 2026-11-23

### Changed

- **书库**：扫描与合并按路径键一次建索引（不再逐本全表比对），书架卡片渲染复用缓存；
  下载与元数据并发时列表不再跳动或重复。
- **写盘**：书架与设置按实际变更节流，拖字号滑块、连续改配置只落一次盘。
- **阅读器**：正文排版缓存复用，翻页模式只渲染与当前页相交的段落；打开书籍不再解压封面，
  取封面与书签改为打开抽屉时按需取快照。
- **全文搜索**：改为后台分批扫描 + 虚拟列表，长书搜索时界面保持可交互，关闭阅读器立即停止；
  目录过滤、命中高亮与搜索摘要不再每帧重复分配。
- **空闲开销**：排空循环无任务时把兜底 tick 从 100ms 退避到 500ms，下载中仍保持 100ms。
- **配置**：启动时校验配置并夹取全局字号，手改成 0 或越界值不再让界面不可读。

### Fixed

- **退出落盘**：Cmd+Q、标题栏关窗（含 Windows 原生与 Linux 自绘标题栏）与系统关窗统一走
  同一条落盘路径，阅读器打开时不再丢最近进度与字号改动；每次退出只落盘一次。
- **阅读器**：阅读中禁用导航快捷键（Cmd+1..6 / F6），关闭阅读器后把键盘焦点交还主窗口，
  可直接继续用快捷键切页。
- **搜索**：重新加载后旧搜索回包不再串入新搜索；翻页与滚动模式下命中高亮、页码与正文几何对齐。
- **工具箱**：运行中锁定源文件与输出目录入口；编码探测结果按路径校验，快速换文件不会贴错编码。
- **运行数据**：schema 必须恰好 4 字节才解析，长度异常按损坏处理并进入只读；损坏的
  tasks / sources 先备份再回落且不覆盖旧备份；任务表运行时也按最近 1000 条裁剪。
