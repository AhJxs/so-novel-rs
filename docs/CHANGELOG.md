# Changelog

## [0.7.2] - 2026-11-24

### Added

- **应用内更新**：检查更新后直接在应用内下载、校验并安装新版本，装好后一键重启；
  下载中按「已下载 / 总大小」显示进度，可随时取消。
- **阅读器**：打开书籍时显示加载指示与首次解析提示；阅读设置改为分组列表 + 模态对话框，
  设置打开时方向键、字号与主题快捷键只作用于弹窗。
- **书库**：卡片网格支持键盘操作（Tab 进入，方向键 / Home / End 移动，Enter 或空格打开），
  收藏按钮带提示文字与选中态。
- **工具箱 / 搜索**：工具类型卡片与选项改为标准按钮，可 Tab 聚焦、Enter / 空格激活。

### Changed

- **底层**：升级 gpui-kit 0.11，渲染后端换为 gpui-fast。
- **布局**：对话框宽度、表格列宽、行高与侧栏宽度随全局字号缩放；页头留在滚动区外，
  滚动条贴窗口边缘，不再比内容内缩。
- **移除书架**：不再弹确认框，改为直接执行并在通知里提供「撤销」。

### Fixed

- **对齐**：语源页健康状态标记右对齐失效；搜索结果行在最小窗口宽度下把尾部按钮挤出可视区。
- **冗余刷新**：书库自动扫描、书源规则文件列表与搜索缓存不再每帧重算或重建，
  流式搜索结果也不再反复留存整表快照。
- **表单弹窗**：搜索页「按 URL 下载」与「章节范围」改用普通对话框，确认框只留给破坏性操作。
- **文案**：设置页两个间隔项的描述、下载记录删除标题、弹窗按钮省略号、启动失败提示
  与各页错误提示统一走本地化。
